# Components

- AuthGate decides from both the address and the page actually on screen (canShowPage), because the router keeps the previous page mounted while it moves, so a signed-out visitor never glimpses an inside page and a signed-in member never glimpses login.
- RoomGames posts each game result as a normal room chat line through sendRoomMessage, so results reach everyone inside without new SQL; games are listed in src/lib/room-games.ts and only "ready" ones can be played.
- AuthGate calls deviceCheckIn (src/lib/device-check.functions.ts, SQL in supabase/015_device_bans.sql) on every open so the IP comes from server request headers; a failed check never blocks the app.
- Profile pictures are cropped in the browser (react-easy-crop + canvas in src/lib/crop-image.ts) before Cloudinary upload, so stored avatars/album pictures are already square and small; the profile cover reads album-or-avatar through coverPictures().
- Store frames are drawn by HeadwearFrame as a 150%-wide square centered over the round avatar (pointer-events off), keeping avatar placement untouched; when a frame is worn, the adjacent text block receives a small conditional start margin (ms-2 on Me, ms-3 in ProfileDetails) so decor does not visually crowd display names or IDs; a frame with svga_url plays it there through SvgaPlayer (svgaplayerweb, loaded only in the browser, parsed once per file and shared) with the still art_url as fallback, and store reads drop svga_url when the column is missing; AppScreen's footer slot holds bars that must stay below scrolling content (store purchase, backpack wear).
- The room is rendered once by KeptRoom in __root (RoomView), not by its route, so leaving its page only minimizes it ("احتفاظ بالروم") with voice, mic seat and heartbeat still running; room-keeper.ts holds which room is kept, and a minimized room closes its sheets and skips entrances/gift videos.
- NativeAppBridge handles the Android back button (close sheet, else previous page, else home, else send the app to the background — never quit) and asks for the microphone once on first launch.
