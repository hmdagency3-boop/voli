- The Android app (capacitor.config.ts, android/) is a Capacitor shell that loads the hosted site through server.url instead of bundling the build, because server functions (voice tickets, device checks) must run on the server; native permissions such as the microphone are declared in android/app/src/main/AndroidManifest.xml.
- Launcher icons, round icons, adaptive foregrounds and splash screens are all derived from one logo picture; regenerate every density together when the logo changes. .github/workflows/android-apk.yml builds the APK on GitHub, taking the site address from the CAP_SERVER_URL repository variable and versions from the run number.
