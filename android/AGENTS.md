- The Android app (capacitor.config.ts, android/) ships the interface inside the APK: `bun run build:native` makes a TanStack SPA build (VITE_NATIVE_APP=1) packed into dist/native, because the app must run from the phone and reach the database directly; server functions still run on the published site (VITE_SITE_URL), reached through createStart serverFns.fetch in src/start.ts, with src/server.ts and the CSRF middleware allowing only the app origins in src/lib/native-app.ts. Native permissions such as the microphone are declared in android/app/src/main/AndroidManifest.xml.
- Launcher icons, round icons, adaptive foregrounds and splash screens are all derived from one logo picture; regenerate every density together when the logo changes. .github/workflows/android-apk.yml builds the APK on GitHub, building the interface first, taking the site address from the optional VITE_SITE_URL repository variable and versions from the run number.
