# بصمة الجهاز وسجل الـ IP

1. شغّل `sql/025_device_fingerprint.sql` في محرر SQL لقاعدة فولي، بعد `015_device_bans.sql` (و`016_unified_bans.sql` إن كان مشغّلاً). يمكن إعادة تشغيله بأمان.
2. تطبيق أندرويد يرسل عبر `voli_report_device_v2` بيانات الهاتف الحقيقية: Android ID (من Capacitor Device.getId)، Widevine ID (مشفّر SHA-256)، بصمة عتاد، الطراز والشركة واللوحة والمعالج والرام والشاشة، شركة الاتصالات، VPN، محاكي/روت.
3. IP الهاتف الحقيقي يُقرأ من ترويسات الطلب في قاعدة البيانات، ويُحفظ كل IP استخدمه الهاتف في سجل (`member_device_ips`)؛ الـ IP نفسه يتغير بتغير الشبكة، فالثابت هو معرّف الجهاز والبصمة.
4. حظر جهاز بقيمة البصمة أو `android:<id>` أو Widevine يمنع الهاتف حتى لو أُعيد تثبيت التطبيق أو دخل حساب آخر.
5. صفحة الأجهزة: افتح أي صف لترى كل التفاصيل وسجل الـ IP والحسابات الأخرى على نفس الهاتف.

حدود: IMEI والرقم التسلسلي لا يتيحهما أندرويد 10+ للتطبيقات العادية، وكل ما يرسله التطبيق يمكن التلاعب به من تطبيق معدّل؛ البصمة تقاوم إعادة التثبيت لا العبث المتعمّد.
