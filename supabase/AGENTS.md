# Database updates

- Video gifts live in supabase/019_video_gifts.sql: room_gift_catalog.video_url (Cloudinary-only, set via admin_set_gift_video) and a closed room_gift_shows table filled by a statement trigger on room_coins, so send_room_gift stays unchanged; rooms poll room_gift_shows_since and nextGiftShows (src/lib/gifts.ts) skips videos sent before entering.
- Member extras live in member_info: gender/country from supabase/020_gender_country.sql, birthday/album from 021_profile_extras.sql and age from 022_profile_age.sql (the latest file redefines profile_info: album and age computed from birthday for everyone, birthday self-only, country hidden while hide_location is active); the table is closed and written only by set_my_* functions; src/lib/profile-info.ts is the client entry point and the /me/edit page is where members change them.
- Phone details and IP history live in supabase/025_device_fingerprint.sql (same file as the panel's sql/025): voli_report_device_v2 calls the existing seven-argument voli_report_device first so 015/016 ban rules stay untouched, then saves fingerprint/IDs/hardware jsonb and one closed member_device_ips row per IP; device bans written for a fingerprint, Widevine ID or android:<id> match too.
- 023_store.sql is the management panel's own sql/023_store.sql copied unchanged (UUID items, frame/ride, style/days, store_buy/store_equip); the app reads store_items and member_items under RLS, so change it only together with the panel.
- Lucky/crazy gifts live in supabase/026_lucky_gifts.sql: room_gift_catalog.kind picks the tab; send_room_lucky_gift splits each cost into receiver share (room_coins/charisma), platform cut and a per-kind prize pool, and pays wins only from that locked pool row (a win the pool cannot cover drops to a smaller multiplier or none), so the platform can never pay out more than it took in; pools and spins are closed tables, and src/lib/lucky.ts mirrors multipliers for badges only.
